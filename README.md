# MEC DXF Converter

Локальный конвертер чертежей деталей Lantek. Запускается из командной строки на Node.js 22 или новее с поддержкой OpenSSL Legacy Provider.

| Вход | Выход |
|---|---|
| MEC 8.00, 8.1, 8.2, 9.2 | DXF в миллиметрах |
| MEC 8.2 | MEC 9.2 |
| MEC 9.2 | MEC 8.2 |

Для DXF отрезки, окружности и дуги записываются геометрическими объектами. Текст и точки помещаются на вспомогательные слои. Сообщения о технологических заходах, вырожденных элементах и ссылках на растровые изображения выводятся при конвертации. Для MEC → MEC сохраняются записи исходной детали, а упаковка записей приводится к целевой версии.

## Доступ к параметрам формата

Данные MEC 8.x и 9.2 зашифрованы. Для работы нужен один из двух локальных источников.

- `--lantek-dir` указывает основную папку совместимой установки Lantek с DLL. Конвертер читает библиотеки как данные. Запускать Lantek не требуется.
- `--key-file` указывает файл параметров формата. В этом режиме достаточно Node.js, исходного MEC и параметров нужной версии. DLL и установленный Lantek не требуются.

Файл параметров использует текстовый синтаксис NestPro. Каждое значение ниже обозначает 16 байт в шестнадцатеричной записи.

```text
line-key = <параметр для 8.x>
file-key = <параметр для 9.2>
file-iv = <вектор для 9.2>
```

Для экспорта в DXF нужны параметры версии входного MEC. Для перехода между версиями нужны параметры обеих версий. При записи MEC с `--lantek-dir` передайте `--target-reference` с рабочим местным файлом целевой версии. Конвертер по нему подбирает параметры и оформление выходного файла. С файлом параметров один однозначный набор для целевой версии можно использовать напрямую. Указание эталона позволяет воспроизвести оформление конкретной установки.

## Запуск

Один MEC в DXF с локальным файлом параметров.

```shell
node --openssl-legacy-provider convert.cjs --to dxf --out plate.dxf --key-file ./local/format-keys.txt plate.mec
```

Папка MEC в DXF с сохранением дерева, включая пустые папки.

```shell
node --openssl-legacy-provider convert.cjs --to dxf --out ./drawings-dxf --lantek-dir "C:/Lantek/Expert" ./mec
```

Преобразование из 9.2 в 8.2 с использованием рабочего образца формата.

```shell
node --openssl-legacy-provider convert.cjs --to 8.2 --out plate-82.mec --lantek-dir "C:/Lantek/Expert" --target-reference reference-82.mec plate-92.mec
```

Для обратного перехода между версиями укажите `--to 9.2` и образец 9.2. Укажите новый путь назначения. При пакетном запуске ошибки перечисляются по файлам, а остальные детали продолжают обрабатываться.

Проверку совместимости MEC → MEC завершает импорт в целевую версию Lantek. Автоматические проверки подтверждают упаковку записей, обратное чтение и геометрию DXF.

## Проверки

```shell
npm test
```

Проверки создают синтетические детали и параметры формата во временной папке. Исходный код и тесты автономны.
